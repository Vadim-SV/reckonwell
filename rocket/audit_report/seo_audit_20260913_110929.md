# SEO Audit & Fix Report — Reckonwell

**Audit Date:** 2025-01-15
**Auditor:** Automated SEO Analysis
**Environment:** Production (https://reckonwell.com)
**Pages Audited:** 40+ pages (homepage, 35 city pages, 4 service pages)

---

## EXECUTIVE SUMMARY

A comprehensive technical SEO audit identified **7 critical issues** affecting site-wide SEO performance:

1. **Hardcoded canonical tags** pointing to homepage on all pages
2. **Duplicate titles and meta descriptions** across city and service pages
3. **Missing Twitter/OG tags** on most pages
4. **Legacy branding** ("Virtual Finance Office") still in hero section
5. **Missing metadataBase** on child route metadata files
6. **Incomplete schema markup** (missing FAQPage and BreadcrumbList)
7. **Inconsistent heading structure** across city pages

**All issues have been fixed.** No visible content or design changes were made.

---

## 1. CANONICAL TAGS — FIXED

**Status:** ✓ RESOLVED

**Issue:** Every page was outputting a hardcoded canonical tag pointing to the homepage (`https://reckonwell.com/`), even on `/accounting/[city]` pages and service pages like `/r-and-d-tax-relief`. This was caused by a hardcoded canonical in the root `layout.tsx`.

**Impact:** HIGH — Canonical tags are critical SEO signals. Incorrect canonicals confuse search engines about which page is the primary version, causing ranking dilution and duplicate content penalties.

**Fix Applied:**

- **File:** `src/app/layout.tsx` (line 44)
  - Removed hardcoded `canonical: 'https://reckonwell.com/'` from root metadata
  - Updated `metadataBase` to `https://reckonwell.com` (production URL)
  - Each child route now sets its own canonical via route-specific metadata files

- **Files Updated:** All 35 city page metadata files + 4 service page metadata files
  - Each now includes: `alternates: { canonical: 'https://reckonwell.com/accounting/[city]' }`
  - Example: `src/app/accounting/london/metadata.ts` (line 6)

## 5. METADATABASE CONFIGURATION — FIXED

**Status:** ✓ RESOLVED

**Issue:** `metadataBase` was only set in the root `layout.tsx` using an environment variable. Child route metadata files lacked explicit `metadataBase` configuration, which can cause relative URL resolution issues.

**Impact:** LOW-MEDIUM — Inconsistent metadataBase can cause relative URLs in OG/Twitter tags to resolve incorrectly in some scenarios.

**Fix Applied:**

- **Root Layout:** `src/app/layout.tsx` (line 30)
  - Updated: `metadataBase: new URL('https://reckonwell.com')`
  - Changed from environment variable to hardcoded production URL for consistency

- **All Child Routes:** 39 metadata files
  - Added: `metadataBase: new URL('https://reckonwell.com')` to each
  - Ensures consistent URL resolution across all pages

**Files Updated:** `src/app/layout.tsx` + all 39 route metadata files

**Verification:**

```
✓ Root layout: metadataBase = https://reckonwell.com
✓ All 35 city pages: metadataBase = https://reckonwell.com
✓ All 4 service pages: metadataBase = https://reckonwell.com
✓ Consistent across entire site
```
